我们看到一张图片时，会注意颜色、轮廓和物体。计算机接收到的，却是一组排列整齐的数字。

**卷积神经网络，也就是 CNN，尝试从这些数字里学出有用的特征，再用特征完成任务。** 这篇先围绕图像分类，走一遍从输入到输出的过程。

不必先记住所有网络名称。我们先解决三个问题：一个卷积核到底算了什么？特征图的尺寸为什么会变化？最后的分类分数又从哪里来？

## 1. 一张图片，在网络里是什么样子

先考虑一张高、宽都是 32 像素的 RGB 图片。它有红、绿、蓝三个通道，可以看成三张叠起来的二维数表。

在本文采用的 PyTorch 约定中，一批图片的形状写成 `N × C × H × W`：

| 符号 | 含义 | 本文示例 |
| --- | --- | --- |
| N | 一批输入的数量 | 4 |
| C | 通道数 | 3 |
| H | 图像高度 | 32 |
| W | 图像宽度 | 32 |

因此，`[4, 3, 32, 32]` 表示一批四张这样的图片。先记住这些维度的含义，后面的结构就容易读了。输入、输出通道的定义可对照 [PyTorch 的 Conv2d 文档](https://docs.pytorch.org/docs/main/generated/torch.nn.Conv2d.html)。

## 2. 卷积：拿一小块区域，做一次加权求和

为了方便手算，暂时只看一个通道，把图像缩成 `4 × 4` 的数表。再准备一个 `2 × 2` 的卷积核；核里的数字就是这一小步计算用到的权重。

<figure>
  <img src="/images/cnn/convolution.svg" alt="四乘四输入的左上角二乘二区域，与权重为一、零、零、负一的卷积核逐项相乘求和，得到输出左上角的一。" width="840" height="360" loading="lazy" />
  <figcaption>图 1：先算左上角，再把窗口向右移动。此例步长为 1、不填充，偏置为 0。</figcaption>
</figure>

输入左上角的四个数是 `1、2、3、0`。和卷积核的对应位置相乘，再相加：

<div class="formula-block">1 × 1 + 2 × 0 + 3 × 0 + 0 × (−1) = <strong>1</strong></div>

这个 `1` 就放到输出的左上角。接着把窗口右移一格，使用**同一个卷积核**重复计算；一行结束后，再往下一行移动。

最终会得到这张 `3 × 3` 的输出，也叫一张特征图：

```text
 1   1  -2
 2  -3   1
 0   0   2
```

这里的核是为了演示而手工指定的，不能据此断言它已经学会识别某种物体。严格按数学术语说，上面没有翻转卷积核，执行的是互相关；深度学习里仍通常把这一层称为卷积层。[《动手学深度学习》对这项运算有完整说明](https://d2l.ai/chapter_convolutional-neural-networks/conv-layer.html)。

### 用公式写出这一步

把刚才的计算写成数学公式，会更容易看清「逐项相乘，再相加」的结构。对于**单个输入通道、步长为 1、无填充**的情况：

$$
Y_{i,j} = b + \sum_{u=0}^{K_h-1} \sum_{v=0}^{K_w-1} w_{u,v}\,X_{i+u,j+v}
$$

这里，$X$ 是输入，$w_{u,v}$ 是卷积核对应位置的权重，$b$ 是偏置；$K_h$ 和 $K_w$ 分别是卷积核的高度和宽度。$Y_{i,j}$ 表示输出第 $i$ 行、第 $j$ 列的数，求和符号 $\sum$ 就是在把窗口内的乘积全部加起来。

在前面的手算例子中，$K_h=K_w=2$、$b=0$，代入左上角窗口就得到 $Y_{0,0}=1$。公式描述的，正是图 1 中的那次计算。

## 3. 为什么反复使用同一个卷积核

CNN 的设计有两个值得先记住的特点：

- **局部连接**：一格输出先观察输入中的一小片区域。
- **参数共享**：同一输出通道在不同空间位置重复使用同一组卷积权重。

比如，同一条边缘可能出现在图像左边，也可能出现在右边。共享权重让同一种计算能够在不同位置使用，而不必为每个位置单独学习一套权重。这个结构也不意味着网络天然能应对任意平移或旋转；最终表现仍需通过数据检验。[Stanford CS231n 的卷积网络讲义介绍了这些设计思路](https://cs231n.github.io/convolutional-networks/)。

面对 RGB 输入时，普通卷积的一个输出通道会综合三个输入通道的结果。若使用 `16` 个输出通道，就得到 `16` 张特征图，它们的权重可以学得不同。

一个 `3 → 16`、核大小为 `3 × 3`、`groups=1` 且包含偏置的卷积层，参数量为：

<div class="formula-block">16 × (3 × 3 × 3 + 1) = <strong>448</strong></div>

括号里的 `+1` 是每个输出通道的偏置。这里数的是模型参数，和输出特征图一共有多少格是两回事。

## 4. ReLU 和池化，各做一件什么事

### ReLU：加入非线性

ReLU 对每个数执行 `max(0, x)`。例如，`[-3, 0, 2]` 经过它后变成 `[0, 0, 2]`，张量形状不变。

只叠加线性或仿射变换，整体仍然是仿射变换。加入非线性，才能让组合后的模型表达更丰富的关系。[ReLU 的具体定义见 PyTorch 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.ReLU.html)。

### 最大池化：缩小空间尺寸

本文使用 `2 × 2`、步长为 `2` 的最大池化。它在每个窗口里取最大值，例如下面这个窗口会输出 `4`：

```text
1  4
2  3
```

对 `32 × 32` 的特征图，这种设置会得到 `16 × 16` 的空间尺寸；每个通道分别处理，通道数不变。它会丢掉部分位置信息，因此缩小尺寸也伴随着信息损失。[MaxPool2d 文档给出了窗口与步长的定义](https://docs.pytorch.org/docs/2.14/generated/torch.nn.MaxPool2d.html)。

## 5. 输出尺寸，不用靠猜

先限定在普通卷积、`dilation=1`，并且上下各填充 `P` 格的情况。高度可以这样计算，宽度同理：

$$
H_{\mathrm{out}} = \left\lfloor \frac{H_{\mathrm{in}} + 2P - K}{S} \right\rfloor + 1
$$

这里 `K` 是卷积核高度，`S` 是步长，`⌊ ⌋` 表示向下取整。对于高度为 `32`、卷积核为 `3` 的输入：

| 填充 P | 步长 S | 输出高度 |
| --- | --- | --- |
| 0 | 1 | 30 |
| 1 | 1 | 32 |
| 1 | 2 | 16 |

因此，下文代码中的 `kernel_size=3, padding=1` 配合默认步长 `1`，会保留高、宽。[更一般的尺寸公式包含 dilation，见 Conv2d 的 Shape 部分](https://docs.pytorch.org/docs/main/generated/torch.nn.Conv2d.html)。

## 6. 接起来：一个小型图像分类网络

下面用两组「卷积 → ReLU → 最大池化」提取特征。第一组输出 `16` 个通道，第二组输出 `32` 个通道；两次池化把空间尺寸从 `32 × 32` 缩到 `8 × 8`。

接下来用 `AdaptiveAvgPool2d((1, 1))`，把每个通道的空间区域平均成一个数。于是 `32` 张特征图变成 `32` 个数，再交给线性层，得到 `10` 个类别分数。[自适应平均池化会按指定的输出空间尺寸汇总特征，并保留通道数](https://docs.pytorch.org/docs/main/generated/torch.nn.AdaptiveAvgPool2d.html)。

在装有 PyTorch 的 Python 环境中，可以用下面的代码查看前向传播的输出形状：

```python
import torch
from torch import nn

model = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
    nn.Conv2d(16, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
    nn.AdaptiveAvgPool2d((1, 1)),
    nn.Flatten(start_dim=1),
    nn.Linear(32, 10),
)

# 用随机张量模拟一批 4 张 RGB 图像，只检查结构。
x = torch.randn(4, 3, 32, 32)
model.eval()

with torch.no_grad():
    logits = model(x)

print(logits.shape)  # torch.Size([4, 10])
```

沿着数据流，尺寸变化如下：

| 经过的操作 | 输出形状 N × C × H × W，或 N × 特征数 |
| --- | --- |
| 输入 | `4 × 3 × 32 × 32` |
| 第一层卷积与 ReLU | `4 × 16 × 32 × 32` |
| 第一次最大池化 | `4 × 16 × 16 × 16` |
| 第二层卷积与 ReLU | `4 × 32 × 16 × 16` |
| 第二次最大池化 | `4 × 32 × 8 × 8` |
| 全局平均池化 | `4 × 32 × 1 × 1` |
| 展平 | `4 × 32` |
| 线性层 | `4 × 10` |

这里得到的是 `logits`，也就是未经归一化的分类分数。如果训练时使用 PyTorch 的交叉熵损失，直接传入 logits；不需要先手动做 softmax。[交叉熵接口的输入要求见官方文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.cross_entropy.html)。

> 这段代码只演示网络结构和尺寸变化。输入是随机数，参数也没有训练，输出不能说明模型已经具备图像识别能力。

## 7. 卷积核里的数字，怎么学出来

真正的学习发生在训练中。一个基本循环是：用图像得到预测分数；结合标签计算损失；通过反向传播求出参数的梯度；再由优化器更新参数。许多批次、许多次更新之后，权重才可能逐渐形成对任务有用的模式。

PyTorch 的自动微分会跟踪相关计算，并在调用反向传播时计算梯度。[官方 autograd 教程解释了这个过程](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)。

所以，看懂网络结构只是起点。若要判断它是否学得有效，还要在独立的验证或测试数据上观察表现，不能只看训练时的结果。

## 8. 用三个问题检查自己的理解

1. 一个卷积核移动到右边时，权重会重新换一套吗？
2. 使用 `Conv2d(3, 16, 3, padding=1)`，输入高、宽为 `32` 时，输出通道和空间尺寸分别是多少？
3. 程序打印出 `[4, 10]`，能说明模型已经分得准吗？

对应答案是：**不会，同一输出通道共享权重；输出为 16 个通道、32 × 32 的空间尺寸；不能，形状正确和预测有效需要分别验证。**

下一次遇到一张 CNN 结构图，可以先沿着箭头标出形状，再检查每一步在做什么。把这些小步骤连起来，网络就不再只是一串陌生的层名称了。
