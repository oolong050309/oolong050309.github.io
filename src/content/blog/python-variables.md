刚学编程时，我们常把变量理解成盒子。在 Python 里，换个比喻可能更顺手：变量是贴在对象上的名字。

## 两个名字可以指向同一个对象

```python
a = [1, 2]
b = a
b.append(3)

print(a)  # [1, 2, 3]
```

这里没有自动复制列表。`a` 和 `b` 指向同一个列表，因此通过 `b` 修改列表，也能通过 `a` 观察到变化。

## 重新绑定名字是另一回事

```python
a = [1, 2]
b = a
b = [7, 8]

print(a)  # [1, 2]
```

`b = [7, 8]` 创建了另一个列表，并让名字 `b` 指向它。原来的列表没有被这次赋值修改。

## 想要独立副本怎么办

对于只有简单元素的列表，可以先使用浅拷贝：

```python
a = [1, 2]
b = a.copy()
b.append(3)

print(a)  # [1, 2]
```

浅拷贝只复制最外层容器。如果列表里面还有可变对象，内部对象依然可能共享。需要复制整个对象结构时，再根据具体情况考虑 `copy.deepcopy()`。

## 先画箭头 再猜结果

遇到不理解的赋值代码，试着把名字写在左边、对象画在右边，再用箭头连接。分清“修改对象”和“重新绑定名字”，许多意外结果就能解释了。
